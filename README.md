# Live Meeting App

Peer-to-peer video calling application built with React, Vite, and PeerJS.

## Features

- Host creates a call by selecting a pre-recorded video and generating a shareable link
- Guest joins via the link and streams their live camera back to the host
- WebRTC peer-to-peer connection via PeerJS
- Mobile-compatible with playsInline, muted, and autoPlay attributes
- Session persistence locks the guest screen after call ends
